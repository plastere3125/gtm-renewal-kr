# GTM 코스메틱스 국문 메인 시안 — 아임웹 적용표

- 기준: 최종 운영은 아임웹 디자인 모드. 이 저장소의 HTML·CSS·JS는 **화면 확인용 시안**이며 아임웹에 자동으로 옮겨지지 않습니다.
- 상품·회원·장바구니·결제·구매평은 운영 단계에서 아임웹 기본 기능(상품 위젯, 게시판·구매평 위젯, 쇼핑 기능)에 연결합니다.
- 계정의 코드 삽입 권한(추가 CSS, 코드 위젯, 헤더/바디 코드)은 **미확인** 상태입니다. 「추가 CSS」「코드 위젯」 항목은 권한 확인 후 적용 여부를 정합니다.
- 구분: **기본 위젯** = 섹션·이미지·텍스트·버튼·상품 위젯으로 재현 / **추가 CSS** = 기본 위젯 + 스타일 보정 / **코드 위젯** = HTML·JS 직접 삽입 필요 / **별도 확인 필요** = 아임웹 기능 범위 확인 후 결정

## 공통

| 영역 | 구성 | 구분 | 비고 |
|---|---|---|---|
| 헤더 | 로고, 대메뉴 5개 + 하위 메뉴 드롭다운, 검색·로그인·장바구니 | 기본 위젯 | 현재 사이트 헤더 설정에서 디자인만 조정 |
| 모바일 메뉴 | 햄버거 → 대메뉴 펼침(하위 메뉴 2열) | 기본 위젯 | 아임웹 모바일 메뉴 사용, 2열 배치는 추가 CSS |
| 상품 카드 가격 표기 | 정가 취소선 + 할인율 + 판매가, 가격문의 | 기본 위젯 | 상품 위젯 표시 옵션 |
| 상품 미리보기(모달) | 카드 클릭 시 이미지·가격·소개 팝업 | 별도 확인 필요 | 운영에서는 상품 상세 페이지 이동이 기본. 미리보기는 시안 검토용 |
| 푸터 | 연락처·사업자 정보·약관 링크·KOR/ENG | 기본 위젯 | 하단 자동 사업자정보 줄은 아임웹 강제 표시(10/29 확인) |
| Pretendard 서체 | 본문·제목 | 추가 CSS | 아임웹 디자인 설정의 서체 목록에 없으면 웹폰트 CSS 필요 |
| 시안 이동 바 | A안/B안/선택 화면 이동 | 해당 없음 | 시안 검토용, 운영 반영 안 함 |

## A안 · 피부 과학의 정제된 아름다움

| 순서 | 섹션 | 구성 | 구분 | 비고 |
|---|---|---|---|---|
| 1 | 히어로 | 전폭 신제품 배너 장면 + 왼쪽 웜화이트 패널 위 카피·버튼 / 아래 「이 장면의 제품」 버튼 띠 | 기본 위젯 + 추가 CSS | 아임웹 이미지 배경 섹션 + 텍스트·버튼. 원본 문구를 가리는 그라데이션 패널은 추가 CSS, 또는 **문구 없는 배너 원본(PSD)을 받아 배경 이미지로 쓰면 기본 위젯만으로 가능** |
| 2 | 브랜드 철학 | 큰 문장 + 링크 4개(브랜드 스토리·히스토리·OEM·글로벌) | 기본 위젯 | 텍스트 + 버튼(텍스트형) |
| 3 | 대표 라인(피디렌자) | 좌: 크리스탈 마스크 큰 카드 / 우: 세럼·크림·세트 가로형 카드 | 추가 CSS | 상품 위젯은 세로형 카드가 기본 → 가로형 배치는 CSS 보정. 대안: 이미지 + 텍스트 위젯 조합 |
| 4 | 성분 이야기 | 3열(NMN·PDRN·Pearl Tomato®) 설명 + 카테고리 링크 | 기본 위젯 | 3단 텍스트 |
| 4-1 | 피부 일차자극 시험 | 설명 + 9개 제품 결과 표 | 기본 위젯 | 텍스트 위젯 표 기능 또는 표 이미지. 시험 결과 갱신 시 표 수정 |
| 5 | 제품 컬렉션 | 탭 6개(세럼/앰플·크림·마스크·토너·클렌징·스킨 부스터) + 상품 그리드 | 별도 확인 필요 | 아임웹 상품 위젯의 카테고리 탭 기능 사용 가능 여부 확인. 불가 시 카테고리별 상품 위젯 + 탭 위젯 또는 코드 위젯 |
| 6 | 브랜드 소식 | 포스터 1장 + 행사 목록 3건 | 기본 위젯 | 운영에서는 뉴스 게시판 최신글 위젯 연결 권장 |

## B안 · 나에게 맞는 스킨케어를 발견하다

| 순서 | 섹션 | 구성 | 구분 | 비고 |
|---|---|---|---|---|
| 1 | 히어로(분할형) | 좌: 핑크 배경 카피 + 바로가기 칩 5개 / 우: 연출 장면 2장 자동 전환(펩티큘 모델 → 신제품 라인업) + 장면별 제품 버튼 | 기본 위젯 + 별도 확인 필요 | 2단 섹션 + 슬라이드(갤러리) 위젯. 슬라이드 위 제품 버튼 배치는 위젯 기능 확인 필요. 불가 시 장면 아래에 버튼 배치 |
| 2 | 제품군 바로가기 | 8개 타일(이미지·이름·제품 수) + 선택한 제품군 상품 가로 목록 | 코드 위젯 또는 별도 확인 필요 | 타일 선택에 따라 아래 목록이 바뀌는 동작은 기본 위젯으로 어려움. 기본안: 타일 클릭 → 해당 카테고리 페이지 이동(기본 위젯만으로 가능) |
| 3 | 리뉴얼 2026 | 상품 가로 슬라이더 + 이전/다음 버튼 | 별도 확인 필요 | 상품 위젯의 슬라이드형 지원 여부 확인. 불가 시 4열 그리드 |
| 4 | 라인으로 고르기 | 좌: 라인 6개 목록 / 우: 라인 소개 + 상품 | 코드 위젯 또는 별도 확인 필요 | 기본안: 라인별 섹션을 세로로 나열하거나 탭 위젯 사용 가능 여부 확인 |
| 5 | 성분으로 찾기 | 성분 8개 이미지 칩 + 선택 성분 설명·상품 목록 | 코드 위젯 또는 별도 확인 필요 | 기본안: 성분 칩 클릭 → 「성분별 솔루션」 하위 카테고리 페이지 이동 |
| 6 | 실제 구매평 + GTM 소식 | 구매평 카드 + 행사 목록 + 인스타그램 버튼 | 기본 위젯 | 구매평은 아임웹 구매평(게시판) 위젯, 소식은 뉴스 게시판 위젯 연결 |

## A·B 적용 난이도 요약

- **A안**: 대부분 기본 위젯으로 재현 가능. 대표 라인의 가로형 카드와 제품 탭만 보정이나 확인이 필요합니다.
- **B안**: 탐색 영역 3곳(제품군·라인·성분)의 「선택하면 아래 목록이 바뀌는」 동작이 핵심입니다. 이 동작은 코드 위젯이 필요하거나, 아임웹 탭 기능 지원 여부를 확인해야 합니다. 코드 삽입 권한이 없으면 카테고리 페이지로 이동하는 방식으로 단순화합니다.
